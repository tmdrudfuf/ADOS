# Requirements Checklist

- [x] Execution policy model is immutable.
- [x] Execution policy model is provider-neutral and project-neutral.
- [x] Execution policy model is serializable and versionable.
- [x] Required policy fields are validated without implicit defaults.
- [x] Primary Repository Guardian detects staged files.
- [x] Primary Repository Guardian detects dirty tracked files.
- [x] Primary Repository Guardian detects unexpected untracked files.
- [x] Primary Repository Guardian supports allowed local paths.
- [x] Primary Repository Guardian detects branch and HEAD mismatch.
- [x] Primary Repository Guardian detects repository mismatch and non-git directories.
- [x] Guardian uses read-only Git operations only.
