# Quickstart: ADOS Doctor

Validate ADOS and a project:

```powershell
python -m ados doctor --project C:\path\to\project --config C:\path\to\project-config.json
```

Machine-readable output:

```powershell
python -m ados doctor C:\path\to\project --config C:\path\to\project-config.json --json
```

Development help/version:

```powershell
python -m ados --help
python -m ados --version
```
