# Requirements Checklist

- [x] Core is project-neutral.
- [x] Primary checkout protection is explicit.
- [x] Worktree-before-write order is explicit.
- [x] Exact HEAD Gate is explicit.
- [x] Independent review cannot be impersonated by implementer self-review.
- [x] Publication and destructive cleanup are human-controlled by default unless every Conditional Autonomous Merge Authority gate is satisfied.
- [x] Broad destructive cleanup is prohibited by default.
- [x] Empty-repository bootstrap exception is narrowly scoped.
- [ ] Foundation docs are present and cross-consistent.
- [ ] Review outcome is recorded.
